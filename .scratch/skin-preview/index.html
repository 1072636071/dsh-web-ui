帮我用 TypeScript 写一个快速排序，要求支持泛型和自定义比较器

大人容禀。此乃支持泛型与自定义比较器之快速排序，以唐风楷书录之：

typescript quick-sort.ts
function quickSort<T>(
  arr: T[],
  compare: (a: T, b: T) => number = (a, b) => a > b ? 1 : -1
): T[] {
  if (arr.length <= 1) return arr;
  const pivot = arr[Math.floor(arr.length / 2)];
  const left  = arr.filter(x => compare(x, pivot) < 0);
  const mid   = arr.filter(x => compare(x, pivot) === 0);
  const right = arr.filter(x => compare(x, pivot) > 0);
  return [...quickSort(left, compare), ...mid, ...quickSort(right, compare)];
}

用法示例：

typescript usage.ts
// 数字排序
const sorted = quickSort([3, 1, 4, 1, 5, 9, 2, 6]);

// 自定义比较器：按对象属性降序
const byAge = quickSort(users, (a, b) => b.age - a.age);
加上单元测试，用 vitest

已为大人备好 vitest 测试用例：

typescript quick-sort.spec.ts
import { describe, it, expect } from 'vitest';
import { quickSort } from './quick-sort';

describe('quickSort', () => {
  it('排序数字数组', () => {
    expect(quickSort([3,1,4,1,5])).toEqual([1,1,3,4,5]);
  });
  it('支持自定义比较器', () => {
    const cmp = (a: number, b: number) => b - a;
    expect(quickSort([1,2,3], cmp)).toEqual([3,2,1]);
  });
  it('空数组与单元素', () => {
    expect(quickSort([])).toEqual([]);
    expect(quickSort([42])).toEqual([42]);
  });
});
